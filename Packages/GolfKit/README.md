# GolfKit

GolfKit is a shared Swift package with models, services, and utilities for 22holes. It uses SwiftData models (iOS 17+ / watchOS 10+). 

Quick start:
- Add the package to your app targets via Xcode or SwiftPM
- Use SDPersistence(inMemory: true) for previews and tests

Models:
- SDCourse, SDHole, SDHazard, SDRound, SDShot, SDClub
